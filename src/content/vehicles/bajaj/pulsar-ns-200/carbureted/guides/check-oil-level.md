---
title: Revisar el nivel de aceite
summary: Lectura del nivel de aceite del motor por la mirilla del cárter.
category: routine
difficulty: 1
time: 5 min
tools:
  - Caballete central
  - Aceite SAE 20W50 API SL, JASO MA
warnings:
  - Revisa el nivel con el motor frío.
  - Si el testigo de presión de aceite parpadea en el tablero, la presión es baja. Detén el motor y revisa el nivel.
specs:
  - { label: Nivel correcto, value: Entre las dos líneas de la mirilla }
  - { label: Aceite, value: "SAE 20W50, API SL, JASO MA" }
sourcePages: "5, 18 y 19"
order: 45
---

1. Apoya la moto sobre el caballete central, en un piso plano. Con el gato lateral la moto queda inclinada y la lectura no sirve.
2. Espera a que el motor esté frío.
3. Mira la mirilla de inspección del cárter: el aceite debe quedar entre las dos líneas.
4. Si está por debajo de la línea inferior, agrega aceite del tipo recomendado de a poco, hasta que el nivel quede entre las dos líneas.

> El cuadro de mantenimiento indica completar el aceite cada vez que haga falta y cambiarlo cada 5000 km.
